## Reamer Research

A backtesting and live trading engine for Python and C++. Each bar is
replayed as a seeded tick path, so stops, targets and limits fill inside the
bar, and every trade can be checked in visual trade diagnostics. The relay
sends the same orders live through your own broker. Runs on Linux, macOS on
Apple silicon, and Windows through WSL2; the free kit runs in Evaluation Mode
without a key.
